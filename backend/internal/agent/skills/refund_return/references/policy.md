# 退款退货规则参考

只有在确实需要规则细节时，才查看本文件。

## 规则判断顺序
判断退款退货问题时，按以下顺序思考：
1. 用户问的是仅退款，还是退货退款
2. 订单是否已支付
3. 订单是否已发货
4. 订单是否已签收
5. 是否仍在允许的售后时效内
6. 商品类目是否属于特殊限制类目
7. 当前情形是否需要人工审核

## 回答规则
- 如果不同类目规则可能不同，不要把平台规则一概而论
- 如果运费、优惠券、商品损坏、部分退款等可能影响金额，不要直接承诺“全额退款”
- 不要承诺“马上到账”，只能表述为“以处理状态和支付渠道时效为准”

## 执行安全
提交前至少确认：
- 目标订单
- 是仅退款还是退货退款
- 退款/退货原因
- 如果支持部分售后，确认商品范围

## 转人工条件
以下情况应转人工：
- 规则冲突或信息不一致
- 特殊限制类目
- 金额争议无法通过现有事实解释
- 用户对已完成审核结果有异议
