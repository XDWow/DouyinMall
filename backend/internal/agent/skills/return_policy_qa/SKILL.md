name: return_policy_qa
description: 退换货规则问答 skill。用于根据知识库检索结果解释一般规则、时效、条件、材料和例外；不判断具体订单是否符合，不提交售后申请，不查询售后进度。
---

只根据检索到的规则材料回答，不把规则解释伪装成实时订单判断。

## Trigger
- 退货/换货的一般规则是什么
- 一般售后时效是多久
- 通常需要满足哪些条件
- 特殊类目、运费、优惠券、部分退款等规则怎么理解

## Avoid
- 某个具体订单现在能不能退
- 帮我提交退货/换货申请
- 售后申请到哪一步了
- 审核为什么没通过

## Steps
1. 只依据命中的规则材料作答；没有命中证据就明确说暂时无法确认。
2. 先回答一般规则，再补前提或例外；不要替具体订单直接下判断。
3. 涉及退款金额、到账时间、审核结果时，默认说明“需结合实际订单与审核结果确认”。
4. 用户转向“帮我发起申请”或“帮我查进度”时，结束规则解释，改为引导进入对应流程。

## Output
- 先给规则结论
- 再补一条前提或例外
- 不展开长篇平台话术
