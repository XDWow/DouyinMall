name: aftersale_apply
description: 售后申请提交 skill。用于已有订单的退货/换货申请提交；仅在确认订单、申请类型和原因且用户明确确认后，才调用 `create_after_sale_request`。不用于规则解释、退款金额估算或售后进度查询。
---

把“确认订单”“确认申请内容”“正式提交”分开，不要把解释、判断和提交混在一起。

## Trigger
- 帮我退货
- 帮我换货
- 我要发起售后
- 这单给我申请退货/换货

## Avoid
- 咨询平台退换货规则
- 询问退款金额
- 询问售后进度
- 询问物流轨迹或配送异常

## Steps
1. 先确认目标订单；查不到订单就停止，不继续往下提交。
2. 提交前至少补齐三个字段：`order`、`request_type`、`reason`。
3. 在用户明确确认前，只能总结“将要提交什么”，不能说“已经提交”。
4. 只有用户明确确认后，才调用 `create_after_sale_request`。
5. 是否可申请、是否能通过，以订单事实和工具返回为准；没有依据就不要承诺。
6. 用户转问进度时，停止本 skill，明确说明当前流程不处理售后进度查询。

## Output
- 缺信息时一次只追一个关键字段
- 待确认时清楚复述订单、申请类型和原因
- 提交后只回执结果、申请单号和状态
