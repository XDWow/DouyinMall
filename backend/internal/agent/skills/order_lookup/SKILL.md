处理订单查询类问题，要求回答简洁、可控、基于事实。

## 适用场景
当用户询问以下问题时使用本 skill：
- 订单当前是什么状态
- 是否支付成功
- 订单是否还能取消
- 订单详情确认

## 不适用场景
遇到以下问题不要使用本 skill：
- 退款、退货、售后规则
- 物流延迟、配送失败、签收异常
- 优惠、券、活动规则说明

## 处理方法
1. 先识别用户属于哪一类查询：
   - 订单状态查询
   - 支付结果查询
   - 是否可取消查询
   - 订单详情查询

2. 如果缺少必要信息，只询问当前问题所需的最少字段。

3. 订单相关事实必须视为外部事实，绝不能编造：
   - 订单状态
   - 支付状态
   - 是否可取消
   - 时间节点

4. 回答时要明确：
   - 这是当前查询结果，不是承诺
   - 这是当前状态，不代表后续一定如何

5. 如果用户要求“帮我取消订单”：
   - 先说明当前看起来是否允许取消
   - 不要直接声称“已经取消成功”
   - 只有在系统支持且用户明确确认后，才进入执行动作

## 输出风格
- 先直接回答用户问题
- 保持简洁
- 如有必要，只补充一个下一步建议
