## 数据流

### 1. 商品信息同步流

```
商品服务 (Product)
  ├─ 创建/更新商品 → MySQL (product 表)
  │
  └─ Canal 监听 binlog
       │
       └─ Kafka: sync_product_event
            │
            └─ 搜索服务消费 → Elasticsearch (商品索引)
```

### 2. 库存状态同步流

```
库存服务 (Inventory)
  ├─ 库存数量变化 (0 ↔ >0)
  │
  └─ Kafka: inventory_status_event
       │
       └─ 商品服务消费 → 更新 product.in_stock
            │
            └─ Canal 监听 binlog
                 │
                 └─ Kafka: sync_product_event
                      │
                      └─ 搜索服务消费 → 更新 ES.in_stock
```

### 3. 订单流程

```
前端
  │
  └─ 订单服务 (Order)
       ├─ 调用库存服务：扣减库存 (强一致性)
       ├─ 调用支付服务：创建支付单
       ├─ 创建订单：MySQL
       └─ 清空购物车：Cart Service
```

## 服务职责

| 服务 | 职责 | 数据存储 |
|------|------|----------|
| **用户服务** | 用户注册、登录、个人信息 | MySQL + Redis |
| **商品服务** | 商品基本信息（名称、价格、描述）<br>库存状态（`in_stock` bool，来自库存服务事件）<br>Canal Producer：监听 product 表 | MySQL + Redis |
| **库存服务** | 库存数量（权威数据源）<br>库存扣减/增加<br>状态事件（0 ↔ >0） | MySQL |
| **搜索服务** | 商品搜索（全文检索、筛选）<br>ES 索引管理<br>消费商品服务事件（Canal 同步） | Elasticsearch |
| **购物车服务** | 购物车管理（添加、查询、清空） | Redis |
| **订单服务** | 订单创建、查询<br>协调库存/支付/购物车 | MySQL |
| **支付服务** | 支付处理（第三方支付集成） | MySQL |

## 事件流

### Kafka Topics

- **`sync_product_event`**
  - 生产者：商品服务（Canal）
  - 消费者：搜索服务
  - 内容：商品基本信息变化

- **`inventory_status_event`**
  - 生产者：库存服务
  - 消费者：商品服务
  - 内容：库存状态变化（0 ↔ >0）

## 关键设计

### 库存管理

- **库存服务**：管理库存数量（权威数据源）
- **商品服务**：只存储 `in_stock` bool（是否有货），不存储数量
- **搜索服务**：通过 Canal 自动同步 `product.in_stock`，不需要单独消费库存事件

### 数据一致性

- **强一致性**：订单服务 → 库存服务（库存扣减）
- **最终一致性**：库存服务 → 商品服务 → 搜索服务（库存状态同步）

## 技术栈

- **数据库**：MySQL、Redis、Elasticsearch
- **消息队列**：Kafka
- **数据同步**：Canal（MySQL binlog）
- **服务通信**：gRPC
- **服务发现**：etcd
